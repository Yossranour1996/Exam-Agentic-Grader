Resource: Interfaces and abstract classes: https://docs.oracle.com/javase/tutorial/java/IandI/abstract.html and https://docs.oracle.com/javase/tutorial/java/IandI/createinterface.html
	- Q1.8 (Thread termination): You mentioned finishing execution (correct), but the other two should be explicit: a thread can terminate due to an uncaught exception, or because it was interrupted/stopped. Resource: Concurrency basics and thread lifecycle: https://docs.oracle.com/javase/tutorial/essential/concurrency/
	- Q2.7 (JDBC driver): Mark lost because there isn’t one universal JDBC driver. Each database requires its own driver (commonly a Type 4 pure Java driver from the vendor). Resource: JDBC overview: https://docs.oracle.com/javase/tutorial/jdbc/basics/index.html
	- Q3.3 (Plural): The expected fill was “Interfaces” (plural). In Java, a class can implement multiple interfaces (but extend only one class). Resource: https://docs.oracle.com/javase/tutorial/java/IandI/createinterface.html
